# Implementar el siguiente slice

1. Lee todas las instrucciones persistentes.
2. Inspecciona `STATUS.md`.
3. Selecciona el único slice `READY` cuyas dependencias estén `DONE`.
4. Cámbialo a `IN_PROGRESS`.
5. Inspecciona código y pruebas.
6. Publica un plan breve.
7. Implementa el slice completo sin ampliar alcance.
8. Ejecuta todos los checks aplicables.
9. Revisa el diff y corrige problemas.
10. Actualiza documentación, decisiones y estado.
11. Marca `DONE` únicamente con evidencia; en otro caso `BLOCKED`.
12. Marca el siguiente slice `READY` solo si sus dependencias se cumplen.

Informa con el formato de `PROMPT_MAESTRO_GROK45.md`.
