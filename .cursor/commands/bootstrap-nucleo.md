# Bootstrap de Núcleo

Realiza exclusivamente S00.

1. Lee `AGENTS.md`, reglas, especificación, estado y decisiones.
2. Inspecciona el repositorio completo de forma no destructiva.
3. Ejecuta los comandos existentes de instalación solo si las dependencias ya están disponibles o el usuario autorizó descargas.
4. Ejecuta baseline de format/check, lint, tipos, tests y build.
5. Identifica código útil, deuda, datos, auth, UI, IA y adaptadores.
6. Detecta cambios del propietario.
7. Clasifica: GREENFIELD, FOUNDATION, FUNCTIONAL o LEGACY_CONFLICT.
8. Crea `docs/execution/REPO_AUDIT.md`.
9. Actualiza `STATUS.md` con el primer slice real.
10. No implementes funciones.

Entrega resultado, evidencia, bloqueos y recomendación.
